# Lesson4.6

## 📌 Описание
Этот проект содержит две части:
1. **Консольная игра с боями** (файл `game1.py`).
2. **Kanban-доска на Tkinter** (файл `main.py`).

## 🚀 Установка и запуск

### 1. Убедитесь, что у вас установлен Python
Проверьте версию Python:
```sh
python --version
```
Проект протестирован на **Python 3.8+**.

### 2. Клонируйте репозиторий
```sh
git clone https://github.com/Alexandr-sys2024/Lesson4.6.git
cd Lesson4.6
```

### 3. Установите зависимости
```sh
pip install -r requirements.txt
```

### 4. Запуск игры
```sh
python game1.py
```
Вы играете против компьютера, по очереди атакуя друг друга.

### 5. Запуск Kanban-доски
```sh
python main.py
```
Графический интерфейс откроется в новом окне.

## 📂 Основные файлы
- **`game1.py`** – консольная игра с боями.
- **`main.py`** – Kanban-доска на Tkinter.

## 🔥 Возможности
✅ Автоматическая боёвка в консольной игре.
✅ Визуальное управление задачами в Kanban.
✅ Простая установка и запуск.
